# Robot Training Portfolio

> 个人机器人工程实训档案
> 郑丁亮 · 深圳职业技术大学 软件工程技术（职业本科）2025 级

## 一、所学方向

- **主攻方向**：机器视觉（工业质检场景，YOLO 实例分割项目实战）
- **兴趣方向**：机器人与智能制造，关注工业机器人视觉引导与在线质检落地
- **本项目定位**：嵌入式机电一体化工程实践——固件开发 + 传感器实验 + 数据分析

## 二、使用工具与技能

- **编程语言**：C++ / Java（课程系统学习）；Python（CarDD 实例分割项目实战、实验数据处理与图表）
- **嵌入式**：ESP32 + Arduino 框架，PlatformIO（本项目主用，W2 起逐步上手）
- **版本管理**：Git / GitHub（个人分支 + Pull Request 工作流）
- **实验方法**：原始数据 CSV 记录、单变量对照实验、可复现实验报告
- **机械**：CAD 建模与 3D 打印（入门学习阶段，本项目结构件）

### 六周路线

